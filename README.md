# CineFacil 
CineFacil es un programa hecho en python que sirve para registrar clientes, mostrar las peliculas disponibles, comprar boletos y ver un resumen de las reservas. Todo se guarda en una lista para llevar el control de lo que hace cada cliente.

## Funciones del sistema
- Muestra las peliculas que estan disponibles.
- Permite ingresar el nombre del cliente y la pelicula que quiere ver.
- Se pueden comprar boletos y se calcula el total segun la cantidad.
- Guarda cada reserva en una lista como un diccionario.
- Muestra un resumen con los datos de cada cliente.
- **(Mejora nueva)** Se agrego una funcion que cancela reservas segun el nombre.

## Mejora realizada
Se creo una rama llamada `cancelar-reserva` donde se agrego una funcion para eliminar reservas si el cliente ya no va a asistir. Despues se hizo un merge hacia la rama principal (`main`) y se subieron todos los cambios al repositorio.
